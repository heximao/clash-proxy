# find-duplicates

扫描仓库全部 YAML 规则文件，检查重复规则并生成报告。

## 功能

递归扫描仓库根目录下所有 `.yaml` 文件（自动跳过 `reject.yaml` —— 该文件由 Loyalsoldier 上游机器生成、本地从不编辑，其内部及跨文件重复均属预期），提取每一条规则（`- ` 开头的列表项），检查两类重复：

- **跨文件重复**：同一条规则出现在多个文件中；
- **文件内重复**：同一条规则在同一个文件中出现多次。

## 用法

```bash
python3 scripts/find-duplicates/find_duplicates.py
```

扫描根目录锚定在脚本所在位置向上两级（即仓库根目录），**从任意工作目录执行均可**，无需先 `cd` 到仓库根。

## 输出

运行后在本目录（与脚本同级）生成两份报告：

- `DUPLICATES.md`：人类可读的 Markdown 报告，纳入 git 跟踪；
- `duplicates.json`：机器可读的 JSON，包含每条规则所在文件列表（`rule_map`）与每个文件的内部重复项（`file_dups`）。体积较大，仅在本地生成、未纳入 git 跟踪，需要时运行脚本即可重新生成。

报告中列出的文件路径均为相对仓库根目录的路径，与运行时工作目录无关。

## 退出码

无任何重复时为 `0`；存在跨文件或文件内重复时为 `1`（报告两种情况下都会生成），可直接作为 shell / CI 门禁。终端同时打印两类重复的数量汇总；具体重复了哪些规则需查看 `DUPLICATES.md`。
