## 环境变更：git 代理 7893 失效，改直连

- 本机 git 全局配置 `http.proxy` / `https.proxy` = `http://127.0.0.1:7893`，本次运行该端口无监听（ClashX 未运行），`git fetch` 报 `Failed to connect to 127.0.0.1 port 7893`。
- **实测 GitHub 直连可达（`curl --noproxy '*' https://github.com` 返回 200）**，故本次全部 git 操作改用 `git -c http.proxy= -c https.proxy= <cmd>` 临时禁用代理，fetch / pull / push 全部成功。
- 注意：zsh 不会对变量做词分割，`G="git -c ..."; $G fetch` 会报 command not found；改用 shell 函数 `gitx() { git -c http.proxy= -c https.proxy= "$@"; }` 或直接写全。
- RDAP / DoH 等仍需走 7893 代理，后续如做外部查询须先确认端口恢复。
